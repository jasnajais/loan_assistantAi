# 💰 Loan Eligibility Prediction System

A Machine Learning based web application that predicts whether a user is eligible for a loan based on financial and personal details.

## 🚀 Overview

This project helps automate the loan approval process by predicting loan eligibility instantly. Instead of manual verification, users can enter their details and get a quick prediction using a trained ML model.

## 🎯 Problem Statement

Traditional loan approval systems take time and require manual verification. This project solves that by:
- Reducing decision time
- Providing instant eligibility results
- Minimizing human effort

## 🛠️ Tech Stack

- Frontend: HTML, CSS
- Backend: Python (Flask)
- Machine Learning: Scikit-learn
- Data Processing: Pandas, NumPy

## ⚙️ Features

- User-friendly web interface
- Takes input like:
  - Income
  - Employment Status
  - Credit History
  - Loan Amount
- Predicts loan eligibility instantly
- Fast and lightweight application

## 🧠 How It Works

1. User enters details on the web page
2. Data is sent to Flask backend
3. Backend processes input and sends it to the ML model
4. Model predicts eligibility
5. Result is displayed to the user
